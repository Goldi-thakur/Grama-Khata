# Grama Khata 📱

Grama Khata is a modern Android micro-finance ledger app built for small shopkeepers and local vendors to manage customer credits digitally.

## ✨ Features
- Customer credit management
- Give / Take transaction tracking
- Automatic balance calculation
- SMS reminders
- WhatsApp reminders
- One-tap calling
- Transaction history
- Search and sorting
- Dark & Light theme
- Offline local storage

## 🛠 Built With
- Kotlin
- Jetpack Compose
- Android Studio
- Material 3
